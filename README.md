# E-Pharmacy-Price-Comparison-System...
my project is an E-Pharmacy Price Comparison System. The main objective of this project is to help users compare medicine prices available across different online pharmacy platforms. The system collects medicine-related data, processes and compares the prices, and presents the results in a simple format so that users can easily identify the available price options. Through this project, I worked on data collection, data processing, comparison logic and presenting useful information to the user.”
