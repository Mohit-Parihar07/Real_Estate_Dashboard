**about project**

 I developed an interactive Real Estate Analytics Dashboard using Power BI. The main objective of this project was to analyze property sales, revenue, expenses, profit, customer information and geographic performance.

I worked with property, customer and calendar data. First, I cleaned and transformed the raw data using Power Query. Then I created relationships between the tables and built the data model. After that, I created DAX measures for important KPIs such as total revenue, expenses and profit.

Finally, I created interactive visualizations and geographic analysis in Power BI so users can filter the data and understand business performance more easily. This project helped me improve my practical skills in data cleaning, data modeling, DAX and Power BI dashboard development.
